What's New in Clippings 7.2:
• Multiple clippings can be copied from Clippings Manager or Clippings Sidebar. Select the clippings in the order you want them to appear by CTRL- or SHIFT-clicking the clippings and then right-clicking and selecting Copy Clipping Text from the context menu
• You can now set the color label of a clipping from Clippings Sidebar
• A label can be set for multiple clippings by CTRL- or SHIFT-clicking the clippings from Clippings Manager or Clippings Sidebar, and then right-clicking and selecting a label from the context menu
• Clippings with a source web address now display a badge on the clipping icon
• On Firefox 157 and newer, the user interface accent color in Clippings Manager, the New Clipping dialog and other dialog boxes and extension pages is changed to purple, matching the Nova design
