What's New in Clippings for Thunderbird 7.2:
• The Clippings context menu is now available for the subject line in the compose window. A clipping can also be added to the message subject using the keyboard shortcut Alt+Shift+S (Ctrl+Option+V on macOS).
• New preset placeholders for the recipient's first name in the To and Cc fields: $[TO_FIRST_NAME] and $[CC_FIRST_NAME]. To fill in these placeholders during pasting, Clippings will ask for permission to access your contacts when using these placeholders for the first time.
• New option for Sync Clippings users to automatically sync when opening Clippings Manager or the New Clipping dialog
• The user interface accent color in Clippings Manager, the New Clipping dialog and other dialog boxes and extension pages now uses the system accent color, matching the UI colors in the rest of Thunderbird
